

# tkinterCompiler

12/20/2023



进入 `display.py` 所在的文件夹，进入终端输入

```cmd
python ./display.py
```

即可进入页面。



操作说明：

- 在页面中点击 `上传文件` 选择文件上传。 本项目提供 `test.cpp` 以及 `test_simple.cpp` 文件

- 上传文件后点击 `词法分析` 进行词法分析
- 点击 `语法分析` 进行语法分析
- 点击 `中间代码生成` 进行语义分析和中间代码生成

此时主页面可以重新点击 `文件上传` 上传其他文件进行分析，步骤同上。
